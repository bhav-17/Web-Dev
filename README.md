* Images and multimedia

* Basic accessibility concepts

### CSS

* Selectors & properties
* Colors, backgrounds & gradients
* Fonts and typography
* Box model
* Margin & padding
* Borders
* Display properties
* Positioning
* Flexbox
* Responsive layouts
* Hover effects & transitions
* Basic animations
